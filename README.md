
# ETL-пайплайн курсов валют ЦБ РФ

## Описание проекта

Разработан ETL-пайплайн для автоматической загрузки курсов иностранных валют ЦБ РФ в облачную базу данных PostgreSQL (Neon).

С помощью Python данные получаются из JSON API, обрабатываются библиотекой pandas и сохраняются в PostgreSQL с защитой от дублирования записей.

Ежедневная загрузка автоматизирована через Apache Airflow.

Для визуализации разработан интерактивный дашборд на Streamlit, отображающий историю курсов USD, EUR и CNY с возможностью выбора валют.

## Архитектура проекта

Поток обработки данных:

**JSON API → Python → pandas → PostgreSQL → Streamlit**

Apache Airflow управляет ежедневным запуском ETL-скрипта.

### 1. Extract — получение данных

Python отправляет HTTP-запрос к API:

https://www.cbr-xml-daily.ru/daily_json.js

Из полученного JSON извлекаются:

- `rate_date` — дата курса
- `currency_code` — код валюты
- `nominal` — номинал валюты
- `rate` — курс в рублях за указанный номинал

### 2. Transform — обработка данных

С помощью pandas данные преобразуются в DataFrame.

Формируется таблица с четырьмя столбцами:

| rate_date | currency_code | nominal | rate |
|---|---|---|---|
| 2026-10-31 | USD | 1 | 80.5573 |
| 2026-10-31 | EUR | 1 | 89.6603 |
| 2026-10-31 | CNY | 1 | 12.0873 |

### 3. Load — загрузка в PostgreSQL

Подготовленные данные записываются в облачную базу PostgreSQL (Neon).

Для предотвращения дублирования используется ограничение:

`UNIQUE (rate_date, currency_code)`

При загрузке применяется SQL-конструкция:

```sql
ON CONFLICT (rate_date, currency_code)
DO NOTHING
```

Если курс валюты за определённую дату уже находится в базе, повторная запись пропускается.

### 4. Автоматизация через Apache Airflow

Airflow запускает ETL-скрипт по расписанию:

```text
0 8 * * *
```

Ежедневно в 08:00 по московскому времени.

DAG выполняет Python-скрипт `load_currency.py` через BashOperator.

Результаты выполнения и ошибки можно отслеживать через интерфейс Airflow.

### 5. Визуализация через Streamlit

Дашборд получает данные из PostgreSQL и отображает:

- Таблицу исторических курсов валют
- Линейный график изменения курсов
- Интерактивный выбор одной или нескольких валют

Используемые валюты: USD, EUR и CNY.

## Установка и запуск

### 1. Клонирование репозитория

```bash
git clone https://github.com/chauzov108-png/cbr-currency-etl.git

cd cbr-currency-etl
```

### 2. Создание виртуального окружения

Для macOS/Linux:

```bash
python3 -m venv .venv

source .venv/bin/activate
```

### 3. Установка библиотек

```bash
python -m pip install -r requirements.txt
```

Apache Airflow устанавливается отдельно в соответствии с инструкциями для выбранной версии Airflow.

### 4. Настройка подключения к PostgreSQL

Создать файл `.env` на основе `.env.example`.

Указать собственные параметры подключения:

```dotenv
neon_password=YOUR_PASSWORD
neon_host=YOUR_NEON_HOST
```

В текущей реализации используются база `neondb` и пользователь `neondb_owner`. При другой конфигурации PostgreSQL эти параметры необходимо изменить в Python-коде.

Настоящий файл `.env` не публикуется в GitHub.

### 5. Создание таблицы

В PostgreSQL выполнить SQL-скрипт:

```text
sql/schema.sql
```

Скрипт создаёт таблицу `currency_rates` с необходимыми столбцами и ограничением уникальности.

### 6. Ручной запуск ETL

```bash
python load_currency.py
```

Пример результата:

```text
2026-10-31
54
Добавлено строк: 0
```

Последняя строка показывает количество новых записей.

Если новые данные отсутствуют, повторная загрузка не создаёт дубликаты.

### 7. Запуск Streamlit

```bash
streamlit run dashboard.py
```

После запуска открыть:

http://localhost:8501

### 8. Настройка Airflow

DAG расположен в:

```text
dags/currency_rates_dag.py
```

Для автоматического выполнения необходимо настроить Apache Airflow на использование папки `dags` проекта.

DAG запускает `load_currency.py` через Python из виртуального окружения `.venv`.

При локальном использовании компьютер и необходимые процессы Airflow должны работать в момент запуска задания.
